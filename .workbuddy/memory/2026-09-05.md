## 项目：把"普通图统一鲁棒性方法"扩展到文本属性图（TAG）

**背景（老师布置理论研究任务）**
- 老师让用户做理论研究：现有方法是在普通图神经网络上实现"统一性鲁棒性"（推测 = NSPGNN/RGSL，见工作区 neighbor similarity.pdf，作者含珠海学院 Yulin Zhu / Wai Lun LO）。
- 目标：把该方法扩展到文本属性图（TAG）这类新数据集。

**工作区三篇论文定位**
1. `neighbor similarity.pdf` = NSPGNN（arXiv:2401.09754，"Robust Graph Structural Learning Beyond Homophily via Preserving Neighbor Similarity"）：理论 Theorem 1 = 攻击损失更新幅度与 τ 跳聚合邻居特征相似度矩阵 K=A^τX(A^τX)^T 负相关 → 攻击偏好"连接低相似对"；防御 RGSL 双 kNN 图 + 邻居相似性保持传播（低通/高通自适应），跨同配/异配统一鲁棒。很可能就是"这个项目的方法"。
2. `NeurIPS-2023-...benchmarking-and-rethinking.pdf` = CS-TAG benchmark（MSRA，Yan Hao/Chaozhuo Li 等）：大型 TAG 数据集 + PLM/GNN/co-training/拓扑预训练(TPT) 范式评测；发现节点属性文本选择（描述 vs 评论）对 PLM 影响极大。
3. `Robustness in TAG...new defenses.pdf` = TGRB（ICLR 2026，人大 Zhewei Wei 组 + 蚂蚁）：TAG 鲁棒性统一评测框架，10 数据集×4 领域×文本/结构/混合扰动×毒化/逃逸；三大发现：①文本-结构鲁棒性存在固有 trade-off；②GNN/RGNN 性能高度依赖文本编码器与攻击类型；③GraphLLM 对训练数据污染尤其脆弱；防御 SFT-auto。代码 https://github.com/Leirunlin/TGRB —— 直接对标对象。

**TAGLAS（用户提出要用的库）**
- arXiv:2406.14683；github.com/JiaruiFeng/TAGLAS；25 数据集（引文/共购/Wiki/KG/推荐/分子/常识场景图/对话）；5 种任务型（default/default_text/subgraph/subgraph_text/QA）；统一节点/边文本特征结构 + text↔embedding 工具 + 评测工具。
- 注意：多数数据集是把已有图"换皮"附加文本；分子/推荐数据集的"文本"较形式化（SMILES/属性），做文本扰动鲁棒性应优先选文本语义丰富的数据集（arxiv/cora/pubmed/wikics/products…）。

**扩展要点（初步分析，待与用户核对）**
- 文本图本质变化：特征从"一次性固定数值向量"→"原始文本 + 可替换/可微调编码器 E(·)"；由此出现 embed→GNN 与 GraphLLM 两范式。
- 攻击面扩大：结构扰动之外新增文本级扰动（改写/同义词/LLM 生成投毒），即 TGRB 的 hybrid。
- NSPGNN 的 Theorem 1 只对结构扰动成立且固定 X；扩展到文本图 = 把 X 视为 E(text) 并推广到文本+结构混合扰动 —— 这是理论机会点。
- 若走向 GraphLLM 范式，RGSL 的 kNN 图监督无法直接在 token/LLM 表征空间套用。
