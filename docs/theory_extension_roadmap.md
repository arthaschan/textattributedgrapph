# 定理推广研究路线草图：把 NSPGNN 从普通图推到文本图（第 b 步）

> 定位：本组普通图工作 NSPGNN（arXiv:2401.09754）——Theorem 1：攻击损失更新幅值与
> 聚合邻居特征相似度矩阵 K=A^τ X(A^τ X)^⊤ 负相关 → 结构攻击偏好"连接低相似对"；
> 防御 RGSL = 双 kNN 图 + 邻居相似性保持传播，跨同配/异配统一。
> 本文档把该定理与防御推广到文本属性图（TAG），并针对 TGRB（ICLR'26）的缺口
> "有评测、有经验防御(SFT-auto)、无理论"给出可执行研究路线。
> 文档日期：2026-09-05

---

## 1. 一句话主张

**在 TAG 上，文本扰动与结构扰动对分类损失的影响可以分解成"各自独立项 + 一个交叉项"；
结构项正是 NSPGNN 已有的 A^τ X 相似度（攻击偏好连低相似对），文本项是节点嵌入沿"远离本类质心、靠近邻居优势类"方向的偏移；
统一鲁棒性 = 同时抑制这两类偏好——这给出超越 SFT-auto（纯经验）的第一个理论化防御框架。**

## 2. 形式化设定

普通图：G=(V,E,X,Y)，X∈R^{N×p} 固定，结构攻击在 ‖A′−A‖₀≤2Δ_struct 内改 A。
文本图：节点特征来自原始文本 S_v：X=E(S)，编码器 E(·)（可替换、可冻结）。
攻击者预算（对齐 TGRB GMA）：可改边（≤2Δ_struct）**且**改文本（Σ_v 1{S′_v≠S_v}≤Δ_text）。
威胁模型对齐 TGRB：poisoning↔transductive（10/10/80），evasion↔inductive（60/20/20）；默认 transfer，自适应攻击放附录。
符号：SGC surrogate Z=softmax(Â^τ XW)；K(Â^τ X)=Â^τ X(Â^τ X)^⊤；Ω(Â^τ X)[u,v] 为余弦相似。
文本扰动在嵌入空间的像：X′=E(S′)=X+ΔX，其中 ΔX 受编码器约束（同义改写 ‖ΔX‖ 小且方向受限；跨类改写把 X_v 推向异类语义区）。

## 3. 三个研究问题

- **RQ1（可迁移性）**：当 X=E(S) 由预训练编码器给出时，Theorem 1 的结构攻击偏好结论是否仍然成立？成立条件？
  - 预期：成立——Theorem 1 的证明只依赖 surrogate 结构与损失形式，与 X 的来源无关（同配性无关同理可迁移）。需要补的实验：在 TAG 数据上复刻 NSPGNN 论文 Fig.2 的密度图（恶意边 vs 正常边的 Ω(X)/Ω(AX)/Ω(A²X) 分布），验证"低相似对被连"仍可区分。
- **RQ2（文本攻击的几何刻画）**：文本扰动 ΔX 如何影响攻击损失更新？能否证明"文本攻击偏好 = 把节点嵌入推向类间边界的异类方向"（对齐 TGRB 的 neighborhood-aware prompt 目标）？
- **RQ3（统一防御的保证）**：怎样的邻居相似性保持传播对"结构偏好 + 文本偏移"同时免疫？能否给出可验证条件（如对 E 的 Lipschitz 常数、文本扰动幅度的依赖）？

## 4. 推广定理（P1–P4，含证明思路与所需假设）

**P1（结构偏好迁移，轻档）**
> 设定不变、把 X 替换为 E(S)：攻击损失更新 dL_atk ∝ −Tr(Δ Â^τ X(Â^τ X)^⊤ Δ^⊤)，攻击偏好仍 = 连低 ℧(Â^τ X) 对。
> 证明：Theorem 1 原推导（neighbor_similarity.pdf L240-310）对 X 的来源零假设 → 逐字迁移。
> 价值：把"统一性"从"同配+异配"自然延伸到"任意文本编码器"。实验成本极低（c 步 harness 现成）。
> 风险：低。这是论文的"立论第一块砖"，不是卖点。

**P2（文本攻击 = 结构攻击在嵌入空间的替身，中档=核心）**
> 目标：在 SGC surrogate + 小扰动假设下，把"文本级扰动"表示成结构化嵌入扰动 ΔX=Φ(S′,S)，
> 推导 dL_atk 对 (ΔA, ΔX) 的联合二阶展开，得到三项：
>   dL_atk ≈ −[ Tr(ΔA项·K) + Tr(ΔX^⊤·M·ΔX) + Tr(ΔX^⊤·C·ΔA项) ]
> 其中：结构项系数 = K(Â^τ X)（NSPGNN 已知）；文本项系数 M 由"类质心散布矩阵 + 邻居优势类方向"决定；
> 交叉项 C 决定"先改文本再连边"的协同增益（混合攻击为什么更难防）。
> 证明思路：对 L_NLL 在 (Â^τ X W) 处做二阶 Taylor，把 ΔA 与 ΔX 作为两个独立的 Gateaux 方向；
> 文本方向约束取自编码器 E 的局部 Lipschitz（‖E(S′)−E(S)‖≤L·edit(S′,S)）。
> 所需假设：(a) 编码器局部 Lipschitz（可对 MiniLM/RoBERTa 用同义词扰动集实测，给经验界）；
> (b) 文本攻击后节点仍保留"邻居可判性"（否则退化为随机噪声，防御目标变为检测）。
> 价值：这是 paper 的理论核心 + 解释器——用它解释 TGRB 发现 1：
>   **GNNGuard/CosGCN 式余弦门控为什么结构强、文本崩**：门控阈值 τ 是"结构攻击"最优的，
>   而文本攻击把受害节点嵌入推离邻居（℧(X'_v,X_u) 骤降）→ 门控把"本来该保留的良性边"也滤掉，信息全失。
>   数学上：τ 固定时，文本攻击使 benign 边相似度分布左移 → 过滤器漏报率单调上升 → 精度崩。
> 这给出一个可证伪的预测：自适应/按邻居稳定性调阈的过滤器（Guardual 的思路）也救不了文本攻击，
> 因为问题不在阈值而在"相似度本身被污染"——只有让传播对文本偏移免疫才治本。

**P3（文本攻击的"类方向"偏好，可单独成命题）**
> 在 cross-entropy 下，单节点文本改写使损失期望下降最快的方向 = 沿 (s_v − 邻居优势类质心) 的
> 嵌入偏移方向；因此 neighborhood-aware 文本攻击（TGRB prompt 的 (i)(ii) 两条）是近似最优的文本攻击。
> 证明：把 softmax 梯度按类分解，与 NSPGNN 证明同套路（delta = S*−Y 结构）。
> 价值：把 TGRB 的 prompt 攻击"规范化"为嵌入空间的梯度攻击，此后文本攻击可与结构攻击统一到同一损失函数框架，
> 防御端只需防一个几何目标。风险：中——需处理离散文本→连续嵌入的映射（用 P2 的 Lipschitz 桥）。

**P4（统一防御 NSPGNN-T 的可验证鲁棒性上界）**
> 若传播层满足"相似性保持"（℧(Â^τ X̂) 在训练与攻击后仅以 ε 扰动，X̂ 为净化特征），
> 则对任意满足预算的 (ΔA, ΔX)，测试损失的额外增长有上界 O(ε·√Δ_struct + L·Δ_text·√(logN))。
> 设计含义：净化特征 X̂ = 编码器输出经过"语义一致性正则"（同义改写不变性）+ 邻居聚合去噪；
> 再在 X̂ 上做 NSPGNN 的双 kNN 相似性保持传播 → 两类攻击偏好同时被抑制。
> 所需假设：E 的 Lipschitz 常数有经验上界；双 kNN 的 k 与 ε 同阶。
> 风险：上界可能松；退路是只证"文本攻击下 benign 边相似度分布不左移"的单调性定理（弱但干净）。

## 5. 统一防御设计蓝图（NSPGNN-T）

模块（自底向上，每块都有可测的中间指标）：
1. **编码层 E**（冻结预训练 encoder，可选 LoRA 微调）——新自由度。
2. **净化层**：语义一致性正则 R = E[‖E(S)−E(T(S))‖]，T = 同义词/释义扰动集（TGRB 弃用 TextFooler 不等于不能用于训练期正则）；
   加轻量邻居聚合去噪（特征传播到 k 近邻均值，1 轮即可）。
3. **相似性层**：在 X̂ 上算 ℧(Â^τ X̂)，构造正/负双 kNN 图（原 RGSL）。
4. **传播层**：低通沿正 kNN 平滑、高通沿负 kNN 判别 + 自适应门控 α/β（原 NSPGNN）。
5. **训练目标**：分类损失 + 语义一致性正则 + （可选）结构/文本对抗样本的 consistency（TGRB 的 noise 变体证明单靠注入噪声不够——我们的卖点是**在净化特征上的相似性保持**，而非噪声注入）。

与 SFT-auto 的互补叙事：SFT-auto 用 LLM 做**检测+恢复**（推理期、靠语言理解）；NSPGNN-T 用**相似性保持传播**（训练期、靠几何结构）。AutoGCN 证明 GNN 学不会"语言级检测"——所以我们的理论姿态不是去学检测，而是让被污染的文本在传播中自然失效。这正好回应 TGRB future work 第一条（GNN 结构鲁棒 + LLM 语义理解的混合管线）。

## 7. 风险与退路

1. **P2 展开不封闭**：二阶项出现高阶交叉 → 退到"单调性/偏好排序"式弱定理（不做紧上界，只做定性刻画），配合强实验。
2. **文本→嵌入的 Lipschitz 界难给**：对 MiniLM/RoBERTa 实测 synonym-edit 的经验 Lipschitz（有限集上界），论文里作为假设+实证表，不做理论紧界。
3. **P4 上界太松**：弱化为"防御在两类攻击下的鲁棒精度均不低于 X 的充分条件（k、τ 选择准则）"，转成可操作的设计准则而非紧界。
4. **TAG 上异配数据集稀缺**：TAGLAS 无低同配性文本图 → 用 LLMNodeBed 的 History/Photo/Computer/Instagram/Reddit 补（c 步 S4 已安排），并在论文中诚实说明这是跨库迁移验证。
5. **审稿人问"为何不用 GraphLLM"**：正文明确 scope = embed→GNN 理论化（与 TGRB 的 SFT-auto 互补），GraphLLM 混合管线列入 future work（引用 TGRB L680-683 原话方向）。
